# Expense Tracker Backend

Minimal Express + MongoDB backend scaffold for Expense Tracker.

Copy `.env.example` to `.env` and set `MONGO_URI` and `JWT_SECRET`.

Run:

```
npm install
npm run dev
```

Deployment:

- Use `npm start` in production.
- Backend is ready for Render, Railway, or similar platforms.
- Set environment variables `MONGO_URI`, `JWT_SECRET`, and `PORT`.
